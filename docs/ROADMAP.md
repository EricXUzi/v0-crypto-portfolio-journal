# 路线图

以下为候选方向，不代表已经实现或承诺上线时间。欢迎先通过 Issue（问题）讨论真实使用场景。

| 方向       | 计划内容                             | 前置条件                     |
| ---------- | ------------------------------------ | ---------------------------- |
| 交易维护   | 已录入交易的完整编辑及变更记录       | 保证配对收益与修改后记录一致 |
| 多批次收益 | 部分卖出、一买多卖、FIFO（先进先出） | 先明确批次与手续费分摊规则   |
| 持仓快照   | 定期保存余额与历史估值               | 区分资金进出与投资收益       |
| 数据导入   | 交易所 CSV 预览、列映射与去重        | 提供去敏的真实文件样例       |
| 报价身份   | 按链和合约地址配置资产身份           | 明确数据源及网络隐私边界     |
| 使用体验   | 中英文切换、可选择的显示币种         | 先统一金额与日期格式         |

当前以手动记账和完整交易配对为核心。不计划加入自动下单、资产托管或私钥管理。
